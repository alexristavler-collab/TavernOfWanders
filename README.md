# Таверна Чудес — версия с Яндекс Формой

Полностью статическая версия сайта без локальной системы заявок и кабинета владельца.

## Что изменено

- Убрана логика «мастер / не мастер» и весь старый `localStorage` для заявок.
- Убрана старая HTML-форма заявок.
- Заявка теперь отправляется через встроенный `iframe` Яндекс Формы.
- Убраны `owner.html`, `owner.js` и `data/requests.json`.
- Добавлена вкладка «Мастера» с компактными карточками:
  - аватар;
  - имя;
  - жанр;
  - цена.
- Нажатие на карточку открывает анимированное модальное окно с:
  - никнеймом;
  - аккаунтом в соцсети;
  - жанрами игр;
  - системами;
  - поддержкой HB / Homebrew;
  - описанием мастера.

## Подключение Яндекс Формы

Откройте `index.html` и найдите:

`https://forms.yandex.ru/u/REPLACE_WITH_YOUR_FORM_ID/?iframe=1`

Замените URL на URL вашей Яндекс Формы с параметром `?iframe=1`.

Например:

`https://forms.yandex.ru/u/ваш-id/?iframe=1`

## Данные мастеров

Данные находятся в `app.js` в массиве `masters`. Там можно менять имя, никнейм, аватар, жанры, системы, цену, соцсеть, HB и описание.

Сайт остаётся статическим: для работы Яндекс Формы нужен только интернет.
